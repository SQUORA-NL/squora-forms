# Squora.Forms.Blazor.HtmlComponents

Plain HTML implementation of the Squora Forms Blazor components. No third-party UI library required.

```bash
dotnet add package Squora.Forms.Blazor.HtmlComponents
```

```csharp
builder.Services.AddSquoraForms(cfg => cfg.UseDefaultHtmlComponents());
```

Part of [Squora Forms](https://github.com/SQUORA-NL/squora-forms) - open-source, schema-driven forms for Blazor and React. MIT licensed.
