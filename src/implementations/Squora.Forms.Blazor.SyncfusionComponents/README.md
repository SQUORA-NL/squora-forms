# Squora.Forms.Blazor.SyncfusionComponents

Syncfusion implementation of the Squora Forms Blazor components. Requires your own Syncfusion license.

```bash
dotnet add package Squora.Forms.Blazor.SyncfusionComponents
```

```csharp
builder.Services.AddSyncfusionBlazor();
builder.Services.AddSquoraForms(cfg => cfg.UseDefaultSyncfusionComponents());
```

Syncfusion components are subject to Syncfusion's own licensing.

Part of [Squora Forms](https://github.com/SQUORA-NL/squora-forms) - open-source, schema-driven forms for Blazor and React. MIT licensed.
