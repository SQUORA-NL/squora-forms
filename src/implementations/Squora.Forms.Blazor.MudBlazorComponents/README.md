# Squora.Forms.Blazor.MudBlazorComponents

MudBlazor implementation of the Squora Forms Blazor components.

```bash
dotnet add package Squora.Forms.Blazor.MudBlazorComponents
```

```csharp
builder.Services.AddMudServices();
builder.Services.AddSquoraForms(cfg => cfg.UseDefaultMudBlazorComponents());
```

Part of [Squora Forms](https://github.com/SQUORA-NL/squora-forms) - open-source, schema-driven forms for Blazor and React. MIT licensed.
