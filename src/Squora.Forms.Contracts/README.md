# Squora.Forms.Contracts

Interfaces for Squora Forms schema and scope providers.

```bash
dotnet add package Squora.Forms.Contracts
```

Normally installed transitively by `Squora.Forms.Core`.

Part of [Squora Forms](https://github.com/SQUORA-NL/squora-forms) - open-source, schema-driven forms for Blazor and React. MIT licensed.
