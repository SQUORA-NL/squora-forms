# Squora.Forms.Blazor.Actions

Form action components (submit, reset, custom actions) for Squora Forms on Blazor.

```bash
dotnet add package Squora.Forms.Blazor.Actions
```

Normally installed transitively by a UI framework package.

Part of [Squora Forms](https://github.com/SQUORA-NL/squora-forms) - open-source, schema-driven forms for Blazor and React. MIT licensed.
