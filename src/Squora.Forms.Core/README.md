# Squora.Forms.Core

Framework-neutral form model, rules engine and parsing for Squora Forms. No Blazor dependency, so the same form definition can be used from Blazor, React or any other host.

```bash
dotnet add package Squora.Forms.Core
```

Define a form as JSON (JSON Schema + UI Schema + rules) and load it into a `DynamicFormModel`.

Part of [Squora Forms](https://github.com/SQUORA-NL/squora-forms) - open-source, schema-driven forms for Blazor and React. MIT licensed.
