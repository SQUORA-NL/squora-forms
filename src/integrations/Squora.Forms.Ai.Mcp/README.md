# Squora.Forms.Ai.Mcp

MCP (Model Context Protocol) adapter exposing Squora Forms definitions as resources with JSON Schema contracts for AI agents.

```bash
dotnet add package Squora.Forms.Ai.Mcp
```

Part of the Squora Forms Hub integrations.

Part of [Squora Forms](https://github.com/SQUORA-NL/squora-forms) - open-source, schema-driven forms for Blazor and React. MIT licensed.
